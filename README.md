# 🔐 Генератор паролей (Password Generator)

Консольная утилита для генерации надежных паролей заданной длины.

## 🔑 Используемые символы

- **A-Z** (26 букв)
- **a-z** (26 букв)
- **0-9** (10 цифр)
- **!@#$%^&*()** (10 спецсимволов)

**Всего:** 72 возможных символа

## 🚀 Запуск

```bash
javac PasswordGenerator.java
java PasswordGenerator
📸 Пример работы
text
Введите длину пароля: 12

Ваш пароль: aB3#kL9$mN2@

End...
⚙️ Как это работает
Запрос длины пароля у пользователя

Проверка валидности (длина должна быть больше 0)

Генерация случайного символа из общей строки

Повторение до достижения нужной длины

Вывод сгенерированного пароля

📁 Структура проекта
PasswordGenerator.java - основной файл программы

generatedPassword(int lenPassword) - метод генерации пароля

StringBuilder - для эффективной сборки пароля

Random - для генерации случайных индексов

🛠 Технологии
Java 8+

Random для случайных чисел

StringBuilder для сборки строки

try-catch для обработки ошибок ввода

⚠️ Обработка ошибок
Длина пароля ≤ 0 → сообщение об ошибке и выход

Нечисловой ввод → перехват исключения
